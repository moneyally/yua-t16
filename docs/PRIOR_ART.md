## 1. 가장 가까운 선행 연구 — 온칩 상태 상주 FPGA 가속기

### 1.1 arXiv 2603.05931 (2026-03)

> Gupta, Wang, Kannan, Prasanna,
> *A Persistent-State Dataflow Accelerator for Memory-Bound Linear Attention Decode on FPGA*
> https://arxiv.org/abs/2603.05931

| 항목 | 값 | 출처 |

**DR1 과의 관계: 이것이 기준선이다.**

- "상태를 온칩에 상주시킨다" 는 DR1 의 출발점 문장은 이 논문이 이미 하드웨어로 보여준 것이다.
- **패스 수가 결정적이다.** 기준선은 토큰당 **읽기 1 + 쓰기 1**. DR1 v1 은 **3패스**다
  (`p=S·k` 읽기 / `S←α·S+β·err·kᵀ` 읽기+쓰기 / `o=S·q` 읽기). 즉 DR1 은 **상태 트래픽에서
  기준선보다 나쁘다.** 이것은 v1 이 비트 정확 검증을 먼저 잡기 위해 낸 대가이고,
  융합은 `docs/DESIGN.md` 9절대로 W8 이후 과제다. 이 문장을 지우지 말 것.
- 5단계 파이프라인·GVA 헤드 쌍 병렬도 DR1 에 없다. DR1 v1 은 헤드 1개, 직렬 FSM 이다.

### 1.2 arXiv 2601.02135 (2026-01)

> *HFRWKV: A High-Performance Fully On-Chip Hardware Accelerator for RWKV*
> (중산대학교) https://arxiv.org/abs/2601.02135 — 출처 [검색]

- FPGA 기반 RWKV 전용 가속기. **완전 온칩 연산**(off-chip 가중치 접근 제거)이 목표.
- **Δ-PoT 양자화** + 하드웨어 친화적 **하이브리드 정밀도 양자화** 전략.
- 지수·나눗셈 같은 복잡 연산은 **LUT 또는 구간 선형 근사**로 재사용 구조에 넣음.
- 파이프라인 구조: 병렬 행렬-벡터 배열 + 온칩 LayerNorm, 연산 재배열 + chunked double buffering.
- 수치 정확도 수치, 상태 크기: **미확인**.

**DR1 과의 관계:** "고정소수·LUT 로 순환 모델을 온칩에서 돌린다" 는 방향도 이미 있다.
DR1 이 Q1.15 를 쓰는 것은 새로운 발상이 아니라 **같은 계열의 선택**이다.
다른 점은 대상 식(RWKV vs 2절 델타룰)과 검증 방식(비트 정확 골든)뿐이다.

### 1.3 두 논문 대비 DR1 의 위치

| | 2603.05931 | 2601.02135 (HFRWKV) | ORBIT-DR1 |
|---|---|---|---|
| 대상 식 | Gated DeltaNet | RWKV | DESIGN 2절 델타룰 1식, 헤드 1개 |

## 2. 알고리즘 계열 — DR1 이 구현하는 식의 출처

### 2.1 arXiv 2605.22791 (2026-05-21) — 출처 [검색]

> Hatamizadeh, Choi, Kautz, *Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention*
> https://arxiv.org/abs/2605.22791 / 코드 https://github.com/NVlabs/GatedDeltaNet-2

- 채널별 **erase gate b_t** 와 **write gate w_t** 를 분리한다. 둘이 같은 스칼라로 붕괴하면 KDA,
  감쇠까지 붕괴하면 Gated DeltaNet 이 된다 — 즉 **DR1 의 스칼라 α·β 식은 이 계열의 가장 단순한 꼭지점**이다.
- 1.3B / FineWeb-Edu 100B 토큰에서 Mamba-2·GDN·KDA·Mamba-3 대비 최고 성능 보고 (본문 미확인).

**DR1 과의 관계:** DR1 v1 이 쓰는 스칼라 α, β 는 **이 논문이 특수 케이스로 지목한 형태**다.
채널별 감쇠로 확장하는 것은 DESIGN 9절 위험 항목(v2 검토)이며, 확장한다고 새로운 것이 되지 않는다.

### 2.2 arXiv 2607.07953 (2026-07-08) — 출처 [검색]

> Cerruti, Rieder, Rowlands, Jin, Schlag (ETH Zurich),
> *Linear Attention Architectures: Mechanisms, Trade-offs, and Cross-Layer Routing*
> https://arxiv.org/abs/2607.07953

- softmax attention + DeltaNet / Gated DeltaNet / Kimi Delta Attention / Gated DeltaNet-2 를
  **공통 순환 메모리 표기**로 정리하고, 표현력·감쇠·erase/write 제어·학습 처리량·구현 복잡도를 비교.
- 350M / 15B 토큰 중심, DeltaNet 은 1.3B·3B 까지.

**DR1 과의 관계:** "계열" 이라는 말을 쓰기 전에 이 표기법을 따르는 것이 낫다.
DESIGN 1절 각주(KDA 는 채널별 감쇠)의 근거가 여기 있다.

### 3.1 arXiv 2608.15533 (2026-08-16, cs.DC) — 지연 병합 (Q-B 와 직접 충돌)

> Junqing Lin, Jingwei Sun, Guangzhong Sun,
> *DeltaLog: Deferred Materialization of Recurrent States for Linear Attention Decoding*
> https://arxiv.org/abs/2608.15533 — 출처 [사용자] (초록 전문 확인) + [검색]

초록 수준으로 확인된 것:
- 문제: 기존 디코딩 구현은 토큰마다 **전체 순환 상태를 materialize 하고 write-back** 한다.
  상태가 크고 헤드가 많을수록 이것이 메모리 트래픽의 주범이다.
- 방법: 상태를 **dense base state + 최근 compact update 의 유계 로그(bounded log)** 로 표현.
  대부분의 디코드 스텝은 로그에 **append 만**, 주기적 merge 스텝에서 base 로 folding.
- **의미 불변**: 모델이 보는 dense 상태는 eager 디코딩과 동일.
- 구현: **GDN / KDA / RWKV6** 에 적용, 프로토타입 **서빙 스택**에 통합.
- 결과: 순환 상태 갱신 커널 최대 **1.86×**, 프로파일된 상태 쓰기 트래픽 최대 **7.83×** 감소,
  end-to-end 서빙 **1.05~1.20×**.

> **중요 — 이것은 소프트웨어다.** cs.DC, GPU 서빙 스택 대상이며 **하드웨어 가속기가 아니다.**
> BRAM·SRAM 이 아니라 GPU 메모리 계층의 트래픽을 줄인다. DR1 의 문제(온칩 SRAM 포트 경합,
> 사이클 예산)와 **같은 층위가 아니다.**

→ 내가 Q-B 로 적어둔 "스칼라 c 로 감쇠를 미루고 나중에 반영" 은 **아이디어로서는 같은 것의 더 약한
   버전**이다. "새롭다" 고 쓸 수 없다. 남는 틈이 있다면 **층위 차이**(온칩 고정소수 하드웨어)이고,
   그것이 연구 후보 **Q-E** 다 (5절).

### 3.2 arXiv 2608.22354 (2026-08-23, v2 2026-08-25, cs.LG) — 장기 상태 안정화

> Lin, Xu, Liu, Hao, Cai,
> *SANE: State Anomaly Neutralization for Stable Extreme-Context Delta-Rule Models*
> https://arxiv.org/abs/2608.22354 — 출처 [사용자] (초록 확인) + [검색]

초록 수준으로 확인된 것:
- 현상: RWKV-7 을 **1억(100M) 토큰** 문맥까지 밀면 **국소 채널 노름이 폭발**한다.
  **전체 포화가 아니라 국소적**이라는 점이 핵심 관찰이다.
- 방법: **청크 경계에서 tanh 적응 압축** (계수 3 ≤ α ≤ 5) → 안정성과 성능을 동시에 유지.
- 경계: **α ≥ 8 은 안정하지만 추론 능력을 잃는다** (압축이 과하면 정보가 죽는다).

→ 내가 Q-A 로 적어둔 "고정소수 장기 누적 오차 + 주기적 재정규화" 와 문제의식이 겹친다.
   차이는 **부동소수 채널 노름 폭발**(SANE) vs **Q1.15 하드 클립과 LSB 누적**(DR1)이고,
   그 차이가 연구 후보 **Q-F** 다 (5절). **Q-A 는 Q-F 로 흡수한다.**

## 4. 정리 — DR1 이 사실로 말할 수 있는 것

1. 온칩 상태 상주 델타룰 가속기는 **이미 있다** (1.1). DR1 은 그 뒤를 따르고,
   **상태 패스 수에서는 더 나쁘다** (3패스 vs 1+1).
2. 고정소수/하이브리드 정밀도로 순환 모델을 온칩화한 FPGA 가속기도 **이미 있다** (1.2).
3. DR1 이 쓰는 스칼라 α·β 델타룰은 **최신 논문이 특수 케이스로 지목한 형태**다 (2.1).
4. 지연 병합(3.1)과 장기 상태 안정화(3.2)도 **이미 논문이 있다.** 다만 둘 다
   **소프트웨어/부동소수** 층위다.
5. 따라서 DR1 의 내용은 **구현 방식과 검증 방식**이다: 손으로 쓴 RTL, Q1.15 결정론,
   비트 정확 골든 대조, 기존 제어 평면 재사용, d=16 부터. 이것들은 **새로움이 아니라 작업 방식**이다.
6. 보드 실동작·전력·지연 수치는 **DR1 에 아직 없다.** 선행 연구에는 있다.

## 5. 여기서 나온 연구 후보 (계획만, 실행은 승인 후)

`docs/RESEARCH.md` 로 넘긴다. **아직 아무것도 "새롭다" 고 말하지 않는다** — 각 후보는
하드웨어에서 한 사례가 있는지 선행 검색을 먼저 통과해야 한다.

| 후보 | 질문 | 겹치는 선행 | 남는 틈 (가설) |
|---|---|---|---|
| **Q-E** | DeltaLog 식 지연 병합을 **온칩 상태**에 적용. 토큰당 쓰기 패스를 없애고, 읽기 때 로그를 반영하는 비용은 얼마인가. Q1.15 에서 **병합 주기 대 오차**는? | 3.1 (소프트웨어/GPU) | 층위 — 온칩 SRAM 포트·사이클 예산·고정소수 오차. 하드웨어 사례 **검색 필요** |
| **Q-F** | Q1.15 **포화(하드 클립)** vs SANE **tanh(소프트 클립)** 의 장기 안정성·정확도 비교. **`SAT_EVENT` 계수를 적응 압축 트리거로** 쓰는 하드웨어 정책이 되는가 | 3.2 (부동소수/알고리즘) | 고정소수에서의 동작, 그리고 **이미 세고 있는 포화 카운터를 제어 신호로 재사용**하는 부분 |
| Q-C | 세션 상주 스케줄링 | 미조사 | 조사 필요 |
| Q-D | 헤드 간 상태 공유·압축 | 미조사 | 조사 필요 |

Q-A(고정소수 장기 오차)는 **Q-F 로 흡수**했다. Q-B(게으른 감쇠)는 **Q-E 로 흡수**했다.
